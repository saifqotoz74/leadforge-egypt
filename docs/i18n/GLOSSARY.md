# LeadForge Egypt — Approved Terminology Glossary
## Spec Reference: LEADFORGE_SPEC_ADDENDUM_01.md (Section 3.6)

This glossary controls all user-facing terminology in Arabic and English across LeadForge Egypt.
**Core Invariant:** One language per screen. No mixing of English terms inside Arabic UI chrome.

---

## 1. Domain Entities & Operations

| English | Arabic (المصطلح المعتمد) | Notes / ضوابط الاستخدام |
| :--- | :--- | :--- |
| **Lead** | **فرصة** | المصطلح الأساسي في الواجهة؛ "عميل محتمل" يُستخدم فقط في النصوص التفسيرية المطولة |
| **Opportunity score** | **درجة الفرصة** | درجة احتمالية حاجة النشاط لموقع أو إعادة تصميم |
| **Quality score** | **درجة الجودة** | درجة دقة واكتمال بيانات الاتصال والعنوان |
| **Freshness** | **الحداثة** | حالة حداثة التحقق من بيانات الفرصة |
| **Verification / Re-verification** | **التحقق / إعادة التحقق** | توثيق صحة أرقام الهاتف والنشاط التجاري |
| **Claim (purchase a lead)** | **شراء** | الفعل في واجهة المستخدم هو "شراء الفرصة" |
| **Credits / Points** | **نقاط** | الرصيد يُشار إليه بـ "الرصيد" أو "رصيد النقاط" |
| **Ledger** | **كشف الحساب** | سجل حركات النقاط والشحنات والخصومات |
| **Top up** | **شحن الرصيد** | شراء باقة نقاط إضافية |
| **Exclusive / Shared** | **حصري / مشترك** | حصري = مطور واحد فقط، مشترك = حتى 3 مطورين |
| **Matching** | **المطابقة** | خوارزمية مطابقة الفرصة مع خبرة وموقع المطور |
| **Eligibility gates** | **شروط الأهلية** | الشروط الحتمية التي يجب اجتيازها أولاً |
| **Scoring rules** | **قواعد التقييم** | القواعد الرياضية الموزونة لتقييم النشاط |
| **Weight** | **الوزن** | المساهمة الرقمية لكل قاعدة في الدرجة النهائية |
| **Deduplication / Duplicate** | **منع التكرار / مكرر** | الكشف عن السجلات المتطابقة ودمجها |
| **Merge / Unmerge** | **دمج / إلغاء الدمج** | دمج السجلات المكررة في سجل أصلي أو فصلها |
| **Provenance** | **مصدر البيانات** | أصل السجل وسلسلة نسب البيانات |
| **Ingestion** | **استيراد البيانات** | جلب ومعالجة البيانات من المصادر الخارجية |
| **Source / Collector** | **المصدر / المُجمِّع** | أداة تجميع البيانات المحددة |
| **Dead-letter queue** | **السجلات المتعثرة** | السجلات التي فشلت في المعالجة وتحتاج تدخل |
| **Circuit breaker** | **الإيقاف التلقائي للمصدر** | آلية حماية توقف المصدر عند تكرار الفشل |
| **Pipeline** | **مسار الصفقات** | لوحة متابعة مراحل التواصل والبيع |
| **Engagement** | **المتابعة** | خطوات التواصل المباشر مع صاحب النشاط |
| **Feedback** | **الملاحظات** | تقارير المطورين حول جودة الفرصة |
| **Analytics** | **التحليلات** | مؤشرات الأداء والتحويل |
| **Audit log** | **سجل المراجعة** | السجل الأمني لعمليات النظام |
| **Role / Admin / Developer** | **الدور / مدير النظام / مطور** | أدوار المستخدمين في المنصة |
| **Subscription / Plan** | **الاشتراك / الباقة** | خطط الاشتراك الشهرية |
| **Report wrong number** | **الإبلاغ عن رقم خاطئ** | إرسال إشارة جودة لإعادة التحقق واسترداد النقاط |

## 2. Pipeline & Engagement Statuses

| Enum Status | Arabic UI Label | Definition |
| :--- | :--- | :--- |
| `NEW` | **جديدة** | فرصة تم استيرادها حديثاً ومتاحة |
| `CLAIMED` | **تم الشراء** | قام المطور بشرائها وأصبحت في مساره |
| `CONTACTED` | **تم التواصل** | تم الاتصال أو إرسال رسالة أولى للنشاط |
| `REPLIED` | **تم الرد** | قام النشاط بالرد على رسالة أو مكالمة المطور |
| `INTERESTED` | **مهتم** | أبدى النشاط اهتماماً بخدمات تطوير الويب |
| `MEETING` | **اجتماع** | تم تحديد موعد اجتماع تفصيلي مع العميل |
| `PROPOSAL_SENT` | **تم إرسال العرض** | تم تسليم العرض الفني والمالي للعميل |
| `NEGOTIATION` | **تفاوض** | مرحلة التفاوض على شروط العقد والتفاصيل |
| `WON` | **تمت الصفقة** | إتمام التعاقد وبدء المشروع بنجاح |
| `LOST` | **لم تتم** | رفض العميل أو عدم التوصل لاتفاق |
| `NOT_INTERESTED` | **غير مهتم** | النشاط لا يرغب بخدمات ويب حالياً |
| `INVALID` | **بيانات غير صالحة** | رقم هاتف غير صحيح أو نشاط تجاري مغلق |

## 3. Lead Tiers vs. Quality Statuses (No Shared Words)

| Category | Key | Arabic UI Label | English UI Label | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **Lead Tier** | `PREMIUM` | **مميزة** | Premium | أعلى فئة للفرص (صيغة المؤنث لمطابقة "الفرصة"). محظور استخدام "ممتازة" هنا. |
| **Lead Tier** | `HOT` | **ساخنة** | Hot | درجة 70 فأكثر (مؤنث) |
| **Lead Tier** | `WARM` | **دافئة** | Warm | درجة من 50 إلى 69 (مؤنث) |
| **Lead Tier** | `COLD` | **باردة** | Cold | درجة أقل من 50 (مؤنث) |
| **Quality Status** | `EXCELLENT` | **ممتازة** | Excellent | مخصصة حصرياً لجودة واكتمال البيانات. |
| **Action / Nav** | `Explore leads` | **استكشاف الفرص** | Explore leads | التسمية المعتمدة في القوائم والأزرار وحالات الفراغ. |
| **Deal Outcome** | `Won` | **تمت الصفقة** | Won | التسمية المعتمدة للصفقات الناجحة في جميع الشاشات. |

## 4. Latin Script Rules in Arabic Chrome
- **محظور تماماً في واجهة المستخدم العربية:** كلمات مثل `Dashboard, Lead, Claim, Score, Free, Hot, Pipeline, Admin, Settings, Subscription, Credits, Filter`.
- **مسموح فقط بما ورد في `docs/i18n/ALLOWLIST.md`:** أسماء العلامات التجارية، المعرفات التقنية والأكواد في `.ltr-iso` وبخط `--font-mono`، واختصارات القائمة المعتمدة (`CSV`, `SSL`, `URL`, `API`, `ID`, `SaaS`).
